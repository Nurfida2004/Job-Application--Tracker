# Job Application Tracker

A simple web application to track job applications using HTML, CSS, and JavaScript.

## Features

* Add job applications
* Edit applications
* Delete applications
* Search applications
* Filter by status
* Track Applied, Interview, Selected, and Rejected
* Saves data using LocalStorage
* Responsive design

## Technologies

* HTML
* CSS
* JavaScript
* LocalStorage
